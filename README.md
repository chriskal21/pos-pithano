# SamurAI bet

Ιστοσελίδα με πιθανότητες για αγώνες ποδοσφαίρου και μπάσκετ από στατιστικά μοντέλα. Ενημερώνεται μόνη της: πλήρως δύο φορές τη μέρα και κάθε ώρα από τις 12:40 ως τις 22:40 UTC (μόνο τα πρόσφατα, χωρίς αποθήκευση στο αποθετήριο). **Δεν χρειάζεται συνδρομή ούτε κλειδί API.**

- **Ποδόσφαιρο:** Super League, Premier League, La Liga, Serie A, Bundesliga, Ligue 1, Eredivisie, Primeira Liga, Süper Lig, Pro League (Βέλγιο), Premiership (Σκωτία)
- **Ευρωπαϊκά κύπελλα:** Champions League, Europa League, Conference League
- **Μπάσκετ:** EuroLeague, EuroCup, NBA
- **Τένις:** υπολογιστής Elo για τους 60 πρώτους του ATP
- **Σελίδα αγώνα:** φόρμα, προηγούμενες αναμετρήσεις, θέση στη βαθμολογία, «γιατί» και κοινοποίηση (σύνδεσμος `#m/<id>`)
- **Βαθμολογίες:** με πρόβλεψη τελικής κατάταξης από 5.000 προσομοιώσεις (`site/tables.json`)
- **Ιστορικό:** ζωντανές προβλέψεις και εβδομαδιαίος αναδρομικός έλεγχος, με γράφημα βαθμονόμησης
- **Δελτίο / παρολί:** πατάς σε αποδόσεις και αγορές και βλέπεις συνολική πιθανότητα, δίκαιη απόδοση και αξία (αποθηκεύεται στη συσκευή)
- **Εφαρμογή:** εγκαθίσταται στην αρχική οθόνη (`site/manifest.webmanifest`, `site/sw.js`, `site/icons/`) και ανοίγει και χωρίς σύνδεση

## Πώς δουλεύει

```
GitHub Actions (2 φορές τη μέρα)
   └─ scripts/update.py
        ├─ ESPN (δημόσια JSON)        → ποδόσφαιρο και NBA
        ├─ EuroLeague API (επίσημο)   → EuroLeague και EuroCup
        ├─ Tennis Abstract            → Elo τένις
        ├─ data/cache.json            → αποθηκευμένοι αγώνες (κατεβαίνουν μόνο τα καινούργια)
        └─ site/data.json, site/history.json
   └─ δημοσίευση του φακέλου site/ στο GitHub Pages
```

Στο ποδόσφαιρο όλα τα πρωταθλήματα και τα κύπελλα υπολογίζονται μαζί. Οι ευρωπαϊκοί αγώνες συνδέουν τα πρωταθλήματα μεταξύ τους, οπότε το μοντέλο μπορεί να βγάλει πιθανότητες και για αγώνα όπως ΑΕΚ–Man City. Για τον ίδιο λόγο κατεβαίνουν και αγώνες από μικρότερα πρωταθλήματα (Αυστρία, Δανία κ.λπ.), που δεν εμφανίζονται στη σελίδα.

## Εγκατάσταση (μία φορά, περίπου 10 λεπτά)

### 1. Αποθετήριο στο GitHub

1. Φτιάξε λογαριασμό στο [github.com](https://github.com) αν δεν έχεις.
2. Πάτα **New repository**. Όνομα: `pos-pithano`. Επίλεξε **Public**, γιατί το δωρεάν GitHub Pages θέλει δημόσιο αποθετήριο.
3. Στη σελίδα του κενού αποθετηρίου πάτα **uploading an existing file**, σύρε μέσα τους φακέλους `site` και `scripts` και το `README.md`, και πάτα **Commit changes**.
4. Ο φάκελος `.github` είναι κρυφός σε Mac και Windows, οπότε φτιάξ' τον από το GitHub:
   **Add file → Create new file**, γράψε ως όνομα `.github/workflows/update.yml`, κάνε επικόλληση το περιεχόμενο του αντίστοιχου αρχείου και πάτα **Commit changes**.

### 2. Άδεια εγγραφής για τον αυτοματισμό

**Settings → Actions → General → Workflow permissions → Read and write permissions → Save**

### 3. Ενεργοποίηση της σελίδας

**Settings → Pages → Build and deployment → Source: GitHub Actions**

### 4. Πρώτη εκτέλεση

**Actions →** (αν σου ζητηθεί, πάτα το κουμπί που ενεργοποιεί τα workflows) **→ Ενημέρωση προβλέψεων → Run workflow**.

Η πρώτη φορά κρατά 20–40 λεπτά, γιατί κατεβάζει τους αγώνες των τελευταίων 11 μηνών μέρα-μέρα. Οι επόμενες εκτελέσεις παίρνουν 1–3 λεπτά. Η σελίδα θα είναι στο:

```
https://<το-όνομα-χρήστη-σου>.github.io/pos-pithano/
```

## Συχνές ερωτήσεις

**Είναι νόμιμο να παίρνω δεδομένα από το ESPN;**
Τα αρχεία JSON του ESPN είναι δημόσια, αλλά ανεπίσημα και χωρίς τεκμηρίωση. Το ESPN δεν τα προσφέρει ως υπηρεσία και μπορεί να τα αλλάξει ή να τα κλείσει. Το script κάνει λίγα αιτήματα (2 φορές τη μέρα) και κρατά τοπικά ό,τι έχει ήδη κατεβάσει. Αν σκοπεύεις να βγάλεις έσοδα από τη σελίδα, διάβασε τους όρους χρήσης ή σκέψου μια πληρωμένη πηγή.

**Μια μέρα κάποιο πρωτάθλημα δεν εμφανίζεται.**
Η καρτέλα κρύβεται όταν δεν υπάρχουν αγώνες τις επόμενες 8 μέρες (π.χ. διακοπή για εθνικές ομάδες) ή όταν η πηγή δεν απάντησε. Αν μια πηγή αποτύχει, οι υπόλοιπες δουλεύουν κανονικά και στο κάτω μέρος της «Μεθοδολογίας» γράφεται ποια διοργάνωση δεν ενημερώθηκε.

**Το workflow απέτυχε (κόκκινο Χ στο Actions).**
Άνοιξε την εκτέλεση και δες ποιο βήμα απέτυχε:
- «Αποθήκευση» με `Permission denied`: δεν έγινε το βήμα 2.
- Δημοσίευση (`deploy-pages`): δεν έγινε το βήμα 3.
- «Λήψη δεδομένων» με αποτυχία σε όλες τις πηγές: πιθανότατα κάποια πηγή άλλαξε μορφή. Στείλε το μήνυμα λάθους στο Claude για διόρθωση.

Όσο υπάρχει πρόβλημα, η σελίδα μένει όπως ήταν. Δεν αδειάζει ποτέ.

**Θέλω να προσθέσω ή να αφαιρέσω πρωτάθλημα.**
Στην αρχή του `scripts/update.py` υπάρχει η λίστα `FOOTBALL`. Κάθε γραμμή έχει τον κωδικό ESPN (`slug`, π.χ. `eng.1`, `esp.1`, `uefa.champions`) και το όνομα που φαίνεται στη σελίδα. Με `show=False` ένα πρωτάθλημα χρησιμοποιείται μόνο για τις δυνάμεις των ομάδων.

**Πώς ελέγχω αν μια αλλαγή στο μοντέλο βοηθά;**
Το `scripts/evaluate.py` κάνει αναδρομικό έλεγχο σε όλη την περίοδο που υπάρχει στο `data/cache.json`: κάθε εβδομάδα το μοντέλο βλέπει μόνο τα προηγούμενα αποτελέσματα. Δίνει log-loss και RPS (χαμηλότερα = καλύτερα), ποσοστό επιτυχίας και log-loss για Over/Under, μαζί με μια σύγκριση «χωρίς μοντέλο».
```bash
python3 scripts/evaluate.py                         # οι τρέχουσες ρυθμίσεις
python3 scripts/evaluate.py HALF_LIFE=200 FB_PRIOR=4  # δοκιμή άλλων τιμών
```
Τα σουτ στην εστία (από τα στατιστικά του ESPN) ρυθμίζονται μόνα τους: μία φορά την εβδομάδα το workflow δοκιμάζει βάρος 0, 25% και 50% στις τελευταίες 16 εβδομάδες και κρατά ό,τι προβλέπει καλύτερα. Το αποτέλεσμα γράφεται στο `site/history.json` (πεδίο `tune`) και στη «Μεθοδολογία».

**Θέλω άλλες ώρες ενημέρωσης.**
Άλλαξε τη γραμμή `cron` στο `.github/workflows/update.yml`. Οι ώρες είναι σε UTC.

**Δοκιμή στον υπολογιστή μου.**
```bash
python3 scripts/update.py
cd site && python3 -m http.server 8000     # μετά άνοιξε http://localhost:8000
```
